# 任务目标：基于 YOLOv11n-p2 架构与迁移学习的特定物体检测模型训练脚本开发

## 1. 项目背景与应用场景
- **场景描述**：针对小车搭载的 800 万像素、160° 鱼眼摄像头，识别孩子手中拿取的细小物体（笔、橡皮、积木块）。
- **主要挑战**：目标物体极小（如橡皮/笔）、手部遮挡严重、广角鱼眼畸变。
- **任务定义**：编写一个 Python 训练脚本，在 COCO 预训练权重的基础上，使用自定义数据集对 YOLOv11n-p2 模型进行迁移学习与微调。

---

## 2. 硬件与运行环境约束
- **GPU 平台**：NVIDIA GeForce RTX 4070 (12GB 显存)。
- **算力优化要求**：
  - 必须启用 **混合精度训练 (AMP/FP16)** 以降低显存占用并加速训练。
  - 针对 12GB 显存，建议将训练分辨率设置为 **800x800** 或 **1024x1024**（提升小目标识别率），Batch Size 设定为 **16 或 32**（自动适配或提供配置项）。

---

## 3. 数据集规范与自动划分规则
- **原始数据路径**：`Project/request_recogniser/collected_images`
- **标注文件**：由 `auto_marker.py` 生成的 YOLO 格式标注文件（`.txt`，与图片同名存放在同级或对应目录中）。
- **目标类别定义 (nc=3)**：
  - `0`: pen (笔)
  - `1`: eraser (橡皮)
  - `2`: building_block (积木块)
- **数据划分逻辑**：
  - 程序运行前或初始化阶段，自动按照 **85% 训练集 (Train)** 与 **15% 验证集 (Val)** 的比例进行随机划分。
  - 自动生成符合 Ultralytics 规范的 `dataset.yaml` 配置文件（写明 `train`、`val` 路径及 `names` 字典）。
  - **要求**：划分过程需设置固定的随机种子（如 `seed=42`），保证实验可复现。

---

## 4. 模型架构与预训练权重
- **核心架构**：`YOLOv11n-p2`（带有 P2/4x 下采样高分辨率小目标检测头的自定义网络配置文件 `yolov11n-p2.yaml`）。
- **预训练权重**：加载通用 COCO 预训练权重（`yolov11n.pt`）进行骨干网络（Backbone）参数初始化与迁移学习。

---

## 5. 核心功能与编程实现要求

请参考经典分类训练脚本 `Baseline/train_cnn_v2.py` 的工程规范，实现以下模块：

### 5.1 数据准备模块 (`data_prep`)
1. 检查 `collected_images` 目录下的图片与 `.txt` 标注文件匹配度。
2. 按 85%/15% 比例生成文件列表（或划分目录），并在本地生成临时或持久化的 `dataset.yaml`。

### 5.2 模型加载与初始化模块
1. 加载自定义模型结构 `yolov11n-p2.yaml`。
2. 继承 COCO 预训练权重 `yolov11n.pt`（迁移学习）。

### 5.3 训练控制与防过拟合策略
1. **早停机制 (Early Stopping)**：监控验证集 `mAP50-95` 或 `val/loss`，设置 `patience=30`（连续 30 个 epoch 无提升则自动停止）。
2. **学习率调度与正则化**：
   - 采用 Cosine 学习率衰减策略。
   - 配置适度的 Weight Decay 防止过拟合。
3. **数据增强配置（针对小物体优化）**：
   - 启用 Mosaic 增强 (`mosaic=1.0`)。
   - 调整 Scale 范围（如 `scale=0.5`），防止小目标在增强过程中被缩放到不可见。
   - 启用 Copy-Paste 增强以应对手部遮挡问题。

### 5.4 日志记录与模型保存
1. 训练过程中实时打印并记录 Loss、mAP@0.5、mAP@0.5:0.95 等指标。
2. 训练结束后，在终端打印最优模型（`best.pt`）的评估指标，并保存配置文件与权重文件至指定输出目录（如 `runs/train/exp/weights/`）。
