### 需求
编写一个模型训练程序，基于现有的图片迁移训练一个预训练模型。

### 交付要求
一个 Python 程序，可以在预训练架构上针对训练集进行进一步训练。

### 部署位置
代码部署在树莓派 5 代（4GB RAM）上。

### 参考程序
`Baseline/train_cnn_v2.py` 程序，用于训练可以区分五种猫的模型。

### 训练集、验证集图片来源和划分
- 图片来源：`Project/request_recogniser/collected_images` 目录。
- 比例划分：训练集 85%，验证集 15%。

### 采用的架构和预训练权重
- 采用架构：YOLOv11n-p2
- 采用预训练权重：通用 COCO 预训练权重

### 程序实现详细要求
1. 需要加载预训练模型。
2. 需要按 [训练集、验证集图片来源和划分] 中的划分比例划分训练集和验证集。
3. 参考 [参考程序] 的实现，采用合适的迭代轮次数，并通过一定的指标触发早停、防止过拟合。

### 角色与任务定义
你是一位精通 PyTorch 和 Ultralytics 框架的深度学习工程专家。请编写一个用于迁移学习的 Python 模型训练脚本，基于自定义的图片数据集对预训练的 YOLOv11n-p2 模型进行微调（Fine-tuning），以实现对特定小目标（如手持笔、橡皮、积木等）的高精度识别。

---

### 1. 运行环境与算力约束
- **部署平台**：树莓派 5（Raspberry Pi 5, 4GB RAM）。
- **硬件限制与优化要求**：
  - 由于系统内存（4GB）较紧张，请合理控制 `batch` 大小（建议设为 8 或 16）及 DataLoader 的线程数 `workers`（建议设为 2），防止训练过程中内存溢出（OOM）。
  - 支持自动选择设备（若无 GPU 则自动落盘到 CPU/PyTorch CPU 后端训练）。

---

### 2. 数据集来源与自动划分子集
- **原始图片路径**：`Project/request_recogniser/collected_images`（内含图像及同名的 YOLO 标注 txt 文件）。
- **划分比例**：训练集（Train）85% / 验证集（Val）15%（采用随机打乱 split 策略）。
- **数据自动化预处理要求**：
  - 脚本需能自动创建标准的 YOLO 数据集目录结构（如 `dataset/images/train`, `dataset/images/val`, `dataset/labels/train`, `dataset/labels/val`）。
  - 自动扫描原始目录，按比例完成文件拷贝或软链接分发。
  - 自动生成训练所需的 `data.yaml` 配置文件（包含 `train`, `val` 相对路径、类别数 `nc` 以及类别名称映射 `names`）。

---

### 3. 模型架构与预训练权重
- **模型架构**：YOLOv11n-p2（自定义带有 P2 浅层高分辨率特征头的轻量化架构，配置文件参考 `yolov11n-p2.yaml`）。
- **预训练权重**：加载通用 COCO 预训练权重（如 `yolo11n.pt`）作为 Backbone 初始权重，进行迁移学习。

---

### 4. 训练与微调详细逻辑要求
请参考现有的通用训练程序 `Baseline/train_cnn_v2.py` 的工程习惯，完成以下训练逻辑：

1. **结构与权重初始化**：
   - 使用 Ultralytics API 正确加载 `yolov11n-p2.yaml` 模型结构，并转接 `yolo11n.pt` 的预训练权重。
2. **训练超参数设置**：
   - **输入分辨率 (`imgsz`)**：设为 640 或 800（兼顾小目标特征保留与树莓派 5 的计算开销）。
   - **最大迭代轮次 (`epochs`)**：设定为 100 轮。
   - **优化器与学习率**：推荐使用 `SGD` 或 `AdamW`，设置合理的初始学习率（如 `lr0=0.01`）。
   - **防过拟合与数据增强**：
     - 配置 **早停机制（Early Stopping）**：设置 `patience=15`（即验证集 mAP50-95 在 15 个 epoch 内未提升时自动停止训练并保存最佳模型）。
     - 设置 `close_mosaic=10`（最后 10 个 epoch 关闭 Mosaic 数据增强，提升收敛稳定性）。
3. **模型保存与输出**：
   - 训练结束后，在控制台输出最佳 `mAP50` 和 `mAP50-95` 验证指标。
   - 将最终训练好的最佳权重（`best.pt`）保存至 `Project/request_recogniser/weights/` 目录下。
